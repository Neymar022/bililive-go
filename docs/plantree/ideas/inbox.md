## 已采纳

### I1：新增直播间的单次/连续录制模式

- 来源：2026-09-05 用户新增并确认；作为发布修复后的第二批独立交付，详见[实施状态](../plans/video-to-knowledge-lancedb/implementation-status.md#2026-09-05-烧录发布契约根因修复方案澄清)。
- 目标：添加主播直播间时选择录制范围，避免无意持续录制后续每场直播。优先复用现有添加窗口，不额外叠加弹窗。
- 已验现状：前端 `addNewRoom` 固定发送 `listen=true`；后端只有 `IsListening`，停止监听动作可复用，没有单场额度。RecorderStop 同时用于切段，不能作为单次完成依据；现有 LiveSession 不处理短暂离线去抖或跨崩溃续接。
- 已决：当前剩余/下一场；新建 UI 默认单次，旧配置/旧调用缺字段保持连续。三分钟离线确认；无可播放产物等待下一场，字幕失败不恢复额度；重启同场不明暂停待确认。完整决定只维护于实施状态。
