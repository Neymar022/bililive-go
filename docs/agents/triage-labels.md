# Triage Labels

工程 skills 使用五个标准 triage 角色。本文件将这些角色映射到本仓库 issue tracker 中的实际标签。

| mattpocock/skills 中的标签 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给无人值守 agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提到某个角色，例如“应用 AFK-ready triage label”时，使用本表对应的仓库标签。若本仓库以后采用其它标签词汇，只需修改右侧“本仓库标签”列。
